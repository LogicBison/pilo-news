# Industry template - scope, design, verification

**Status:** implemented and verified (2026-11-05) · **Needs:** owner feed portfolio (U5), pilot pick (U6).
**Question:** does the build support generating a website for *any* industry, or only the five seeded verticals?

## Verdict

Yes. Channels are data, not code. A new industry is one admin API call plus
sources; the public site, sitemap, `robots`, theme, locale routes, CTA, lead form,
and `/v1` reads discover it without a deploy. Verified by a contract test that
creates a sixth channel and reads it back through the public API.

## What was already right

- `industries`, `industry_locales`, `sources`, `topics`, `articles` are keyed by
  `industry_id`; no per-vertical deployment or route branching.
- Theme is a JSON token set (`editorial` / `professional` / `academic`), chosen
  by data (`ADR 009`), and rendered through CSS variables.
- Web routes are `[locale]/[industry]/*`; sitemap and metadata are generated
  from the API channel list.
- Scoring keywords accept per-locale topic vocabularies; new topics are data.
- Ingestion partitions by declared source language; no code change per vertical.

## Gap found

The initial implementation could only read/patch the five seeded channels:
there was no create-channel path, so a new industry required SQL. The `seed`
migration is data for the launch five, not a template mechanism.

## Implemented approach

1. `POST /v1/admin/industries` (admin auth + CSRF) creates a channel with slug,
   code, name, theme, localized names/taglines, disclaimers, CTA, timezone,
   retention, sort order, enabled flag, and optional topics.
2. Theme validation reuses the same WCAG AA guardrail as `PATCH`; invalid colors,
   missing tokens, >2 font families, unknown layouts, and low contrast return 422.
3. Reserved slugs (`en`, `es`, `api`, `admin`, `v1`, `health`, `sitemap.xml`,
   `robots.txt`, `_next`, `static`) are rejected; duplicates return 409.
4. The admin console has a `Channels` tab with a layout-preset create form and
   enable/disable control.
5. `docs/adding-an-industry.md` is the operator contract with a curl example.
6. `channels/infrastructure/repo.create_channel` inserts the channel, locale copy,
   and topics in one transaction.

## Residual limits

- A brand-new channel starts with no sources; an operator must add feeds and
  force a refresh (documented).
- `locales` are limited to `en`/`es` in v1; adding a third language still needs
  catalog + prompt + API locale registry updates (ADR 007 additive path).
- Partner routing defaults to no partner until one is created; leads stay `new`
  and visible in the inbox.
- Per-industry domains (U2) are not implemented; canonical uses one host.

## Backups

Volume snapshots replaced `pg_dump`: `./bin/start.sh backup` stops the writers
and archives `pgdata`/`redisdata`/Caddy volumes to one `.tar.gz`; restore is
typed-confirmed and was drilled on 2026-11-05. See
`.work/plans/operations/20261105-backup-restore.md`.

## Host isolation

Each stack gets random host ports (web/API only, bound to `127.0.0.1`) and two
project-scoped networks: `*-net` (app egress + web↔api) and `*-data` (internal
Postgres/Redis). Ports are generated by `./bin/start.sh init-env`.

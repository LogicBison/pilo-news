# Runbooks

**Status:** implemented · **Needs:** owner provider/domain for a real prd deploy.
**Scope:** the operations levers an operator needs after launch.

## Refresh

```bash
./bin/start.sh --env dev refresh                 # CLI, waits for terminal status
curl -X POST "$API/v1/admin/refresh" -b cookies.txt \
  -H "X-CSRF-Token: $CSRF" -H "content-type: application/json" \
  -d '{"industry":"legal","force":true}'
```

A manual run bypasses the schedule but not the single-flight lock; a concurrent
run returns `409` with the active run id. `full_reset` needs
`confirmation: "RESET"` and is audited.

## Feed failure

1. `GET /v1/admin/sources?industry=...` shows `last_error`, `status`,
   `consecutive_failures`.
2. `POST /v1/admin/sources/{id}/test` fetches once without persisting.
3. If the publisher moved, `PATCH /v1/admin/sources/{id}` with the new
   `feed_url`; otherwise disable the source.
4. Check `ingest_fetch_total{status=...}` and the run `stats.errors`.
5. A failed feed contributes nothing; the run finishes `partial`, not `failed`.

## AI outage or budget

1. `AI_ENABLED=false` or remove `AI_API_KEY`; restart api+worker.
2. Headlines and links keep publishing; `summary` is null and the UI says so.
3. Watch `summaries_generated_total{status="failed"}` and
   `ai_estimated_cost_usd_total`; the monthly cap stops summarization only.
4. Restore the key, then `POST /v1/admin/refresh {full_reset:true}` if summaries
   must be regenerated.

## Deploy and rollback

1. Build images tagged `sha-<short>` + `latest`; deploy pins a SHA.
2. Migrations run at API start; wait for `/v1/health`.
3. Smoke: `/v1/health`, `/v1/industries`, one bundle per language.
4. Rollback: re-point `latest` to the previous SHA and restart api/worker/web;
   migrations are forward-only, restore a volume snapshot only if data is
   corrupted.

## Key rotation

1. `POST /v1/admin/api-keys` create the replacement; distribute it.
2. Revoke the old key (`DELETE /v1/admin/api-keys/{id}`); revocation is immediate.
3. Rotate `SECRET_KEY` only with a planned session invalidation: all admin JWTs
   and API-key hashes change.
4. Rotate `AI_API_KEY` by updating `.env.<env>` and recreating api+worker.

## Add an industry

Use `docs/adding-an-industry.md`: `POST /v1/admin/industries`, add sources, force
a refresh. No code deploy is required.

## Logs and metrics

- `./bin/start.sh --env dev logs api` (JSON lines; `request_id` per request).
- `GET /metrics` inside the compose network (Prometheus scrape).
- Alerts: `ops/prometheus/alerts.yml`; dashboards: `ops/grafana/*.json`.
